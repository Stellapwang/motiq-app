MotiQ spiral + audio prototype

Spiral drawing with a concurrent auditory stream. Prototype only — browser millimetres and browser timing are both approximations.

1. Screen calibration

Hold a credit card flat against the screen over the outline below (any ID-1 bank card — they are all 85.60 × 53.98 mm). Adjust until the outline matches the card exactly.

credit card
2. Session
No name is collected. Use a study ID that cannot be resolved to a person without a separate key held elsewhere.
3. Spiral geometry — millimetres, as in motiq_spiral.R
Zone spacing is centre-to-centre for BMIN and BMANT, matching the printed BMANT template.
Sets pitch and turns to match the printed A4 set, so the screen and the paper template are the same geometry.

Lane 0 draws a single line to trace. Set split to 1 for full screen (no tap zone) — appropriate for SP with no audio.

4. Auditory stream
Level is the tone's peak amplitude as a fraction of the loudest signal the device can produce without distorting. 1.0 is full scale, 0.5 is half (about −6 dBFS), 0.25 about −12 dBFS. It is not loudness at the ear — that also depends on the device volume, the speaker, and how far away the participant is.
No response window is applied while recording. Every tap is stored with a raw timestamp and attributed to the nearest preceding tone with no upper bound, so you can choose the window afterwards from the data.
5. Saved trials on this device
Trials are written here the moment they finish, so a failed download or an accidental reload costs nothing. This is browser storage, not a database — clearing Safari's website data erases it. Export at the end of every session. "Show CSV as text" is the fallback if downloads are blocked: select all, copy, paste into a file.

Trial result

CSV is one flat table for analysis: session details repeat on every row, and row_type marks each row as a pen sample, a tap, or a tone. Reads straight into R. JSON is the complete record — calibration, safe area, every parameter, the full sequence, device details — kept nested. Use CSV to analyse, JSON to know exactly what was presented.

t_ms is milliseconds from the trial clock origin: the moment the participant first touched the start dot, or the first tone, depending on how the trial was set to start. Pen samples, taps and tone onsets all share that origin, which is what makes reaction time computable.
