Pen check — per participant

Ask the participant to draw the spiral below, once with each hand. This checks that the stylus registers, that samples arrive at a usable rate, and that pressure varies. A spiral rather than a straight line: the same four numbers come out, but over a longer stroke, so the rate estimate does not depend on how long a line somebody happened to draw — and it rehearses the instruction SP will use. It is a device check, not a trial — no trial record is written.

Mini Trail B — screening, per participant

Ask the participant to join the circles in order — 1, A, 2, B, 3, C, 4, D — in one continuous movement, as quickly as they can without lifting the stylus. Nothing on screen says which circle is next: finding it, and keeping the two sequences in step, is what this screen measures. A move to the wrong circle does not connect — tell them to go back to the last correct one and carry on. The layout is the same every single time it is administered: a covariate whose difficulty varied between administrations would not be comparable. Expect roughly 15–20 seconds.

Run the practice first. It is four circles with the same rules, untimed, and writes no record. Without it the first real administration measures whether the instruction was understood rather than whether the participant can do the task.

Dot tap screen — screening, per participant

Ten seconds. A dot appears somewhere in the box; the participant taps it, and the next one appears somewhere else. Tell them to tap each dot as soon as they see it. A dot that is not tapped within 1.5 s counts as a miss and disappears on its own.

Sound check — per participant

Play both tones at the level the session will use. The participant must hear the difference easily — this is not a discrimination test. Fix the volume here and do not change it during the session.

Saved trials on this device
Trials are written when you press SAVE. This is browser storage, not a database — clearing Safari's website data erases it. Export at the end of every session.

parameters_json carries the complete parameter set verbatim, so a setting added later is still recorded in full for trials run today.

The JSON export is one object with three sections — trials, screening and audio_index. The CSV buttons write the trial rows and the screening rows as two separate files, because they have nothing in common to share columns with.
Screening screens on this device
One row per administration, not per trial. Mini Trail B and the dot tap screen are participant-level covariates and are kept out of the trial file entirely.
Voice recordings on this device
Clips live in IndexedDB, not in the ~5 MB string store the trials use, and each file is named after the trial it belongs to. A bulk download starts one download per clip; Safari may ask permission for multiple downloads, and may refuse them if the page is not in the foreground — download individually if that happens.
